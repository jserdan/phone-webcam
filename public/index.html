🎬 2. Add into OBS Studio

  1. Open OBS Studio on your PC.
  2. Under Sources, click + → Browser.
  3. Name it Phone Camera.
  4. Set the URL to:
http://localhost:8000/obs.html
  1. Set Width to 1920 and Height to 1080 (or 1280x720).
  2. Check "Shutdown source when not visible" (optional).
  3. Click OK.
  4. In OBS Controls, click "Start Virtual Camera"! Now Zoom, Teams, Discord or any app can use your phone camera.
